# 目标电路板上的脚位
| 引脚编号 | 引脚名称 | 功能                                                            |
| -------- | -------- | --------------------------------------------------------------- |
| 1        | PB6      | W 白色通道                                                      |
| 2        | PB5      | **控制电机** (连接到原本电电机驱动IC的2脚)                      |
| 3        | VBAT     |                                                                 |
| 4        | VDDIO    |                                                                 |
| 5        | GND      |                                                                 |
| 6        | BT_RF    | 连接射频天线                                                    |
| 7        | BTOSCI   |                                                                 |
| 8        | BTOSCO   |                                                                 |
| 9        | PA8      | MIC 检测                                                        |
| 10       | PA7      | B 蓝色通道                                                      |
| 11       | USBDM    | 流星灯 LEDC 信号输出（原 220V 50Hz 过零检测点，本产品无此功能） |
| 12       | USBDP    | **控制电机**   (连接到原本电电机驱动IC的5脚)                    |
| 13       | PA2      | G 绿色通道                                                      |
| 14       | PA1      | R 红色通道                                                      |
| 15       | PA0      | **控制电机**   (连接到原本电电机驱动IC的6脚)                    |
| 16       | PB7      | **控制电机**   (连接到原本电电机驱动IC的7脚)                    |

测试时，不使用12脚 USBDP
